# 📚 Library Seat Management System

A simple and user-friendly Library Seat Management System developed to make library seat booking and management easier. This project is built using HTML, CSS, JavaScript, and ElectronJS.

## 🚀 Project Overview

The Library Seat Management System is a desktop application that allows users to manage library seats digitally. Users can check seat availability, book seats, cancel bookings, and monitor booking time through a simple interface.

The application runs as a Windows desktop application using ElectronJS.

## ✨ Features

- **Seat Booking:** Book available library seats.
- **Seat Cancellation:** Cancel booked seats easily.
- **Seat Status:** View available and booked seats.
- **Auto Seat Release:** Automatically releases seats after booking time expires.
- **Live Digital Clock:** Displays the current time.
- **Dark/Light Mode:** Switch between dark and light themes.
- **Seat Filtering:** Filter all, available, and booked seats.
- **Local Data Storage:** Saves booking information using browser LocalStorage.

## 💻 How to Run the Project

### Run as a Desktop Application

1. Install Node.js.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Install dependencies:

```bash
npm install
```

6. Start the application:

```bash
npm start
```

## 📦 Windows Application

A Windows installer can be generated using Electron Builder:

```bash
npm run dist
```

The installer will be available inside the `dist` folder.
